Internship Project Documentation

The File Management & Archiving System was developed during our internship program as part of our academic requirement in the Bachelor of Science in Information Systems. This project represents a practical application of our knowledge in system development, data management, and real-world implementation.

System Overview

The system is designed to improve the organization, tracking, and archiving of operational files through a centralized platform, enhancing efficiency and accessibility of records.
